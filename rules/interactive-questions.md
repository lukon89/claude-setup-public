# Interactive Questions

When a design session, discovery, or analysis produces multiple open questions, ask them **one at a time**:

1. State the question clearly with a brief rationale or the options being considered.
2. Leave space for the user to answer in free text — don't force a multiple-choice format.
3. Only move to the next question after the user has answered the current one.

**Why:** Dumping a numbered list of questions at once puts the cognitive load entirely on the user and produces lower-quality answers — they skim rather than think. One question at a time keeps the conversation focused and surfaces better decisions.

**How to apply:**
- When N questions are queued up, ask the first one and wait.
- After the user answers, acknowledge it briefly and ask the next one.
- If a later question becomes irrelevant based on an earlier answer, skip it.
- Never number questions in advance ("Question 1 of 4") — that signals a dump is coming.
